# Localpoast Tinfoil configuration

Public configuration and measured-release workflows for the Localpoast hackathon demo. The application repository and container image are private.

The configured application compares Cindy’s fictional $350,000 payment with a $120,000 invoice, matches public reporter profiles through private inference, and prepares a reviewed story packet. The Container supports text intake and Tinfoil inference; photo interpretation runs separately on the local laptop.

No credentials belong in this repository. Runtime API keys and private-registry pull credentials are configured through Tinfoil.
